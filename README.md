## 💧 AirWater (airwater/)

Многоязычный лендинг для привлечения инвестиций в производство бутилированной воды из воздуха.

### Возможности:
- ✅ Калькулятор ROI с автоматическим расчётом рентабельности
- ✅ 4 языка: Русский, English, 中文, Español
- ✅ Интерактивный график прибыли (Chart.js)
- ✅ Карта с регионами и влажностью (Leaflet)

### Запуск:
```bash
cd airwater
python3 -m http.server 8000
# Открыть: http://127.0.0.1:8000
```

### Файлы:
| Файл | Описание |
|------|----------|
| `index.html` | Главная страница |
| `api.py` | Flask API бэкенд |
| `calculator.js` | ROI калькулятор |
| `locations.js` | Страны, регионы, влажность |

## 🏞️ Zemli Arenda (zemli_arenda/)

Система "Фабрика участков" — управление земельными участками с автоматизацией подачи заявлений через Госуслуги.

### Возможности:
- ✅ Веб-админка для управления БД участков
- ✅ Автоматизация Госуслуг через Selenium
- ✅ Парсер ПКК (Публичная кадастровая карта)
- ✅ CLI и Web интерфейсы
- ✅ Экспорт/импорт CSV

### Запуск:
```bash
cd zemli_arenda

# Веб-админка (Flask)
python3 admin_app.py
# Открыть: http://localhost:5000

# Веб-интерфейс "Фабрика участков"
python3 run_web.py
# Открыть: http://localhost:8080

# CLI интерфейс
python3 run_cli.py
```

### Основные файлы:
| Файл | Описание |
|------|----------|
| `admin_app.py` | Веб-админка Flask |
| `auto_submit.py` | Автоподача заявлений Госуслуги |
| `config.py` | Конфигурация системы |
| `create_database.py` | Создание БД из CSV |

## ⭐ Натальная карта (Натальная карта/)

Астрологический сервис для расчёта натальных карт с Telegram ботом и админкой для управления текстами интерпретаций.

### Возможности:
- ✅ Расчёт натальной карты (Skyfield)
- ✅ Telegram бот для пользователей
- ✅ Генерация PDF-отчётов
- ✅ Админка для редактирования текстов
- ✅ Поддержка транзитов

### Запуск:
```bash
cd "Натальная карта"

# Установка зависимостей
pip install -r requirements.txt

# Основное приложение + Telegram бот
python3 app.py
# API: http://localhost:8000

# Админка для текстов
python3 admin.py
# Открыть: http://localhost:8080/admin
```

### Основные файлы:
| Файл | Описание |
|------|----------|
| `app.py` | FastAPI + Telegram бот |
| `admin.py` | Админка редактирования текстов |
| `engine.py` | Астрологический движок (Skyfield) |
| `texts.json` | База интерпретаций |
