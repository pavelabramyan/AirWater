Система: "Фабрика участков под НСПД / аренду"

## Статус реализации: ЭТАП 2 ЗАВЕРШЁН ✅

Цель системы:
- Найти свободные земельные участки у государства в Челябинске и области
- Автоматизировать процесс подготовки документов для получения аренды через НСПД
- Автоматизировать создание объявлений для продажи прав аренды
- Масштабировать процесс, чтобы получить 1–2 млн ₽ в месяц с минимальными ручными действиями

## 1️⃣ Модуль поиска участков ✅ (Этап 2 - ЗАВЕРШЁН!)

**Статус:** Реализовано

- Источники данных:
  - ✅ **Публичная кадастровая карта (Росреестр PKK API)**
  - ⏳ Портал градостроительства и ППКР (запланировано)
  - ⏳ Генеральный план города/района (запланировано)
  - ✅ Проверка обременений и арендаторов (через PKK)
- Функции:
  - ✅ **Находит свободные участки** через PKK API
  - ✅ **Проверяет категорию земли** (ИЖС, ЛПХ, коммерция, рекреация)
  - ✅ **Проверяет площадь** участка (фильтр min/max)
  - ✅ **Фильтрует по статусу:** свободные, без арендаторов, без обременений
  - ✅ **Приоритизация по скорингу** (доступность, категория, площадь)
  - ✅ **Поиск по географическим границам (bbox)**

**Реализовано:**
- ✅ PKKParser — асинхронный парсер API Росреестра
- ✅ SearchService — оркестрация поиска и импорта
- ✅ Веб-интерфейс `/search` — форма поиска с параметрами
- ✅ **Поддержка ВСЕХ регионов России** (89 регионов)
- ✅ Справочник координат для популярных городов
- ✅ Автоматический импорт найденных участков
- ✅ Расчёт приоритета каждого участка
- ✅ 5 unit-тестов (100% passed)
- ✅ Документация по источникам данных (`docs/ИСТОЧНИКИ_ДАННЫХ.md`)
