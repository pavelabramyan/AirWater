## 💡 ИСПОЛЬЗОВАНИЕ ДАННЫХ

### Открыть CSV в Excel:
1. Открыть Excel
2. Файл → Открыть → `nspd_export_20251121_200502.csv`
3. Разделитель: **;** (точка с запятой)
4. Кодировка: **UTF-8**

### SQL-запросы к БД:

#### Получить все данные одного участка:
```sql
SELECT column_name, cell_value
FROM nspd_records
WHERE global_row_number = 1
ORDER BY column_index;
```

#### Поиск по кадастровому номеру:
```sql
SELECT DISTINCT global_row_number
FROM nspd_records
WHERE column_name = 'Кадастровый номер/ Условный номер'
  AND cell_value LIKE '%38:30:011801%';
```

#### Статистика по категориям земель:
```sql
SELECT cell_value as категория, COUNT(*) as количество
FROM nspd_records
WHERE column_name = 'Категория земель'
GROUP BY cell_value
ORDER BY количество DESC;
```
