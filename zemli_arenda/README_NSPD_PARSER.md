# Парсер сервиса "Земля для стройки" (НСПД)

## Описание

Скрипт для автоматического парсинга данных из реестра НСПД (https://nspd.gov.ru/construction-nspd/register).

## Возможности

- ✅ Автоматическая авторизация через Госуслуги
- ✅ Обработка SSL-предупреждений
- ✅ Автоматический выбор профиля пользователя
- ✅ Парсинг всех записей (74,577 записей / 1,492 страницы)
- ✅ Сохранение в SQLite БД с возможностью продолжения
- ✅ Подробное логирование процесса
- ✅ Два режима работы: обычный (с GUI) и headless (фоновый)

## Установка зависимостей

```bash
pip install selenium
```

## Структура базы данных

### Таблица `nspd_records`
Хранит данные в нормализованной форме (каждая ячейка - отдельная запись):

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | INTEGER | Первичный ключ |
| page_number | INTEGER | Номер страницы |
| row_number_on_page | INTEGER | Номер строки на странице (1-50) |
| global_row_number | INTEGER | Глобальный номер записи (1-74577) |
| column_index | INTEGER | Индекс колонки |
| column_name | TEXT | Название колонки |
| cell_value | TEXT | Значение ячейки |
| parsed_at | TIMESTAMP | Время парсинга |

### Таблица `parsing_metadata`
Хранит прогресс парсинга:

| Колонка | Тип | Описание |
|---------|-----|----------|
| total_pages | INTEGER | Всего страниц |
| total_records | INTEGER | Всего записей |
| parsed_pages | INTEGER | Спарсено страниц |
| parsed_records | INTEGER | Спарсено записей |
| last_parsed_page | INTEGER | Последняя спарсенная страница |
| started_at | TIMESTAMP | Время начала |
| updated_at | TIMESTAMP | Время обновления |

## Запуск

```bash
python3 parse_nspd_lands.py
```

### Выбор режима

1. **Обычный режим** (рекомендуется для первого запуска):
   - Браузер Chrome виден на экране
   - Можно контролировать процесс
   - SMS-код вводится в браузере

2. **Headless режим** (для фонового парсинга):
   - Браузер работает без GUI
   - SMS-код вводится в терминале
   - Подходит для удалённых серверов

## Процесс работы

1. **Авторизация на Госуслугах**:
   - Переход на gosuslugi.ru
   - Ввод логина: +79295154970
   - Ввод пароля: _4_BW:%rcn6
   - Ввод SMS-кода
   - Выбор профиля "Частное лицо"

2. **Переход на НСПД**:
   - Переход на nspd.gov.ru
   - Обработка SSL-предупреждения
   - Клик "Войти"
   - Обработка SSL-предупреждения для sso.nspd.gov.ru
   - Выбор профиля "Абрамян Павел Рубенович (Частное лицо)"

3. **Настройка таблицы**:
   - Изменение количества записей с 10 на 50
   - Ожидание загрузки таблицы

4. **Парсинг данных**:
   - Парсинг всех 1,492 страниц
   - Сохранение каждой записи в БД
   - Автоматический переход на следующую страницу
   - Паузы каждые 10 страниц для снижения нагрузки

## Возобновление парсинга

Если парсинг был прерван, при следующем запуске скрипт:
- Обнаружит существующие данные в БД
- Предложит продолжить с последней спарсенной страницы
- Продолжит парсинг без дублирования данных

## Примеры SQL-запросов

### Получить все данные для конкретной записи
```sql
SELECT column_name, cell_value
FROM nspd_records
WHERE global_row_number = 1
ORDER BY column_index;
```

### Получить прогресс парсинга
```sql
SELECT 
    parsed_records || '/' || total_records as progress_records,
    parsed_pages || '/' || total_pages as progress_pages,
    ROUND(parsed_records * 100.0 / total_records, 2) || '%' as percentage
FROM parsing_metadata
WHERE id = 1;
```

### Экспорт данных в CSV (через Python)
```python
import sqlite3
import csv

conn = sqlite3.connect('nspd_lands.db')
cursor = conn.cursor()

# Получаем уникальные номера записей
cursor.execute('SELECT DISTINCT global_row_number FROM nspd_records ORDER BY global_row_number')
rows = [r[0] for r in cursor.fetchall()]

# Экспортируем в CSV
with open('nspd_export.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    
    for row_num in rows:
        cursor.execute('''
            SELECT column_name, cell_value 
            FROM nspd_records 
            WHERE global_row_number = ? 
            ORDER BY column_index
        ''', (row_num,))
        
        data = cursor.fetchall()
        
        if row_num == 1:
            # Заголовки
            writer.writerow([d[0] for d in data])
        
        # Данные
        writer.writerow([d[1] for d in data])

conn.close()
```

## Устранение неполадок

### Браузер не запускается
```bash
# Проверьте установку ChromeDriver
which chromedriver

# Обновите ChromeDriver до последней версии
```

### SSL-предупреждение не обрабатывается
- Проверьте логи
- Увеличьте таймауты в коде
- Используйте обычный режим (не headless) для отладки

### Таблица не парсится
- Проверьте структуру таблицы в браузере
- Сделайте скриншот страницы
- Проверьте XPath селекторы
