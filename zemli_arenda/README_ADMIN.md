# 📊 Веб-админка для базы данных земельных участков

## 🚀 Быстрый запуск

### Вариант 1: Через скрипт
```bash
./start_admin.sh
```

### Вариант 2: Напрямую
```bash
python3 admin_app.py
```

## 🌐 Доступ

Откройте в браузере: **http://localhost:5001**

## ✨ Возможности

### 📋 Основные функции:
- ✅ **Просмотр всех записей** - таблица с 50 записями на странице
- ✅ **Фильтры по колонкам** - в каждой колонке есть фильтр
- ✅ **Пагинация** - сверху и снизу страницы
- ✅ **Статистика** - общие показатели в шапке
- ✅ **Адаптивный дизайн** - работает на любых устройствах
- ✅ **Поиск** - мгновенный поиск по любому полю

### 🔍 Доступные фильтры:
1. **Кадастровый номер** - текстовый поиск
2. **Адрес** - текстовый поиск
3. **Район** - выбор из списка
4. **Регион** - выбор из списка
5. **Статус** - выбор из списка (Отправлено/Не отправлена)
6. **Категория земли** - выбор из списка

### 📊 Отображаемые поля:
- ID
- Кадастровый номер
- Адрес
- Район
- Регион
- Статус отправки
- Дата отправки
- Категория земли
- Площадь

## 🎨 Интерфейс

### Статистика в шапке:
- 📈 Всего записей

- **Backend**: Flask (Python)

## 📝 Примеры использования

### Найти все участки в Еткульском районе:
1. В колонке "Район" выберите "Еткульский"
2. Автоматически применится фильтр

### Найти участки по кадастровому номеру:
1. В колонке "Кадастровый номер" введите часть номера (например: "74:07")
2. Нажмите Enter или уберите фокус с поля

### Посмотреть отправленные заявления:
1. В колонке "Статус" выберите "Отправлено"
2. Увидите только отправленные заявления

### Очистить все фильтры:
1. Нажмите красную кнопку "Очистить фильтры" в правом верхнем углу таблицы

## 🔧 Настройка

### Изменить количество записей на странице:
Откройте `admin_app.py` и измените:
```python
ITEMS_PER_PAGE = 50  # Измените на нужное значение
```

### Изменить порт:
Откройте `admin_app.py` и в конце измените:
```python
app.run(debug=True, host='0.0.0.0', port=5001)  # Измените порт
```

## 🐛 Устранение проблем

### Порт занят:
```bash
# Найти процесс на порту 5001
lsof -ti:5001 | xargs kill -9

# Или измените порт в admin_app.py
```

### База данных не найдена:
Убедитесь, что файл `land_records.db` находится в той же папке, что и `admin_app.py`
