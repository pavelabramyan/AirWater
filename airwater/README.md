# AirWater / AquaFuture — лендинг для инвесторов

Современный многоязычный сайт для привлечения инвестиций в производство бутилированной воды из воздуха.

**GitHub:** https://github.com/pavelabramyan/AirWater

## Особенности

- **Калькулятор ROI** — расчёт рентабельности с учётом страны, региона, влажности и производительности установки
- **Сценарии** — консервативный / базовый / оптимистичный (цена, opex, загрузка)
- **NPV и IRR** — дисконтированная оценка проекта (ставка 12%)
- **Сравнение локаций** — таблица ROI по выбранным регионам
- **Секция Бали** — отдельный блок с аргументами для Индонезии (opex 60%)
- **4 языка** — Русский, English, 中文, Español
- **Карта Leaflet** — визуализация регионов и влажности
- **Мобильный wizard** — пошаговый калькулятор на телефоне
- **Форма заявки** — отправка через webhook (Formspree, Make.com, n8n); в заявку попадают параметры калькулятора
- **Адаптивная вёрстка**, анимации, график окупаемости (Chart.js)

## Запуск

1. Откройте терминал в папке проекта
2. Запустите локальный сервер:

```bash
python3 -m http.server 8000
```

3. Откройте браузер: `http://127.0.0.1:8000`

## Конфигурация формы

Отредактируйте `config.js` (или скопируйте из `config.example.js`) и укажите **`webhookUrl`**:

```js
const AWC_CONFIG = {
    webhookUrl: 'https://your-webhook-endpoint',
    contactEmail: 'hello@example.com',
    contactTelegram: 'https://t.me/username',
    contactPhone: ''
};
```

Webhook получает JSON с полями формы и снимком калькулятора (`calculator`, `text`, `calcBlock`).  
Токен Telegram-бота в браузерный JS **не кладём** — проксируйте через Formspree / Make / n8n / Cloudflare Worker.

Без `webhookUrl` форма копирует заявку в буфер обмена.

## CAPEX (источник правды: `calculator.js`)

| Производительность | Инвестиции USD |
|-------------------|----------------|
| 1 000 л/сутки | $150,000 |
| 2 000 л/сутки | $215,000 |
| 3 000 л/сутки | $320,000 |
| 5 000 л/сутки | $470,000 |
| 10 000 л/сутки | $960,000 |

Сумма инвестиции подставляется автоматически при выборе производительности. Минимальный порог в форме заявки — **$150,000** (установка 1000 л/сутки).

## Калькулятор ROI

### Параметры по умолчанию

- **Производительность:** 5000 л/сутки → $470,000
- **Opex:** 75% от выручки (Индонезия — 60%, Россия — 75%)
- **Доля инвестора в прибыли:** 50%
- **Период расчёта:** 1–10 лет (по умолчанию 5)
- **Цена за литр:** подставляется по региону из `locations.js`

### Результаты

- ROI, NPV, IRR (для инвестора)
- Годовая выручка и прибыль
- Окупаемость и точка безубыточности
- График накопленной прибыли
