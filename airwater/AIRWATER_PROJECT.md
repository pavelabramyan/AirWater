# AirWater / AquaFuture — документация проекта (единый источник правды)

## Что это

AirWater (AquaFuture) — статический лендинг для инвесторов в производство бутилированной воды из воздуха.
Ключевая часть лендинга — калькулятор ROI, который использует **данные страны/региона** и **среднегодовую влажность** (влияет на выработку).

## Калькулятор ROI

### Входные параметры

| Поле | Описание |
|------|----------|
| Страна | Выбор из списка |
| Регион | Выбор из списка (локализован на 4 языка) |
| Среднегодовая влажность | Автоматически по региону (readonly) |
| **Производительность установки** | 1000/2000/3000/5000/10000 л/сутки |
| Сумма инвестиции | Автоматически по производительности |
| Цена за литр | Автоматически по региону (можно изменить) |
| Операционные расходы | По умолчанию 75% |
| **Доля инвестора** | По умолчанию 50% |
| Период расчета | 1-10 лет |

### Производительность → Инвестиции

| Производительность | Инвестиции USD |
|-------------------|----------------|
| 1 000 л/сутки | $100,000 |
| 2 000 л/сутки | $200,000 |
| 3 000 л/сутки | $300,000 |
| 5 000 л/сутки | $500,000 |
| 10 000 л/сутки | $1,000,000 |

### Структура инвестиций

| Статья | % |
|--------|---|
| Оборудование (установка + линии) | 50% |
| Аренда и подготовка помещения | 15% |
| Лицензирование и сертификация | 5% |
| Маркетинг и запуск | 10% |
| **Комиссия организатора** | 20% |

### Доля инвестора

- Инвестор вкладывает 100% суммы
- Инвестор получает **50%** от чистой прибыли (настраивается)
- ROI, прибыль и окупаемость рассчитываются **для инвестора**
- Выручка показывается общая по проекту

## API Flask (опционально)

Файл: `api.py`

Запуск:
```bash
pip install flask flask-cors
python api.py
```

API endpoints:
- `GET /api/countries` — список стран
- `GET /api/regions/<country>` — регионы страны
- `GET /api/production-options` — варианты производительности
- `POST /api/calculate` — расчёт ROI

## Как обновлять данные

1. Обновить `locations.js` (для фронта)
2. Обновить `api.py` (для бэкенда, если используется)
3. Обновить `postgres_airwater.sql` (для базы)
4. Проверить на сайте
5. `git add -A && git commit && git push`
6. Создать тег: `git tag -a vX.X.X -m "описание" && git push origin vX.X.X`
